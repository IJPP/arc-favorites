# Favorites — Arc-style app tabs for Chrome

一个 Manifest V3 扩展，把 Chrome 原生固定标签当作持久的 Favorite 应用入口。适配原生横向标签和 Chrome 的 Vertical Tabs；工具栏提供临时管理弹窗，不占常驻侧栏。当前版本 **0.6.0**。

## 安装与升级

1. 打开 `chrome://extensions/`，启用右上角“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本项目的 **dist** 文件夹。
3. 已加载本项目时，点击扩展卡片上的“重新加载”，确认版本为 **0.6.0**。
4. 建议将 Favorites 图标固定到工具栏。升级后刷新已打开的 Favorite 网页，让外链守卫切换到新版。

无需运行服务器。`arc-favorites-chrome.zip` 是同一版本的可分发扩展包，解压后加载其目录。沿用同一个扩展目录升级可以保留现有数据；不用卸载旧扩展。0.6.0 没有新增权限。也可以直接安装 `arc-favorites-chrome-v0.6.0.crx`，扩展 ID 与 0.5.0 的 CRX 相同。

## 0.6.0 更新

**弹窗全面重做**（Preact 重写，Chrome 原生配色 + Arc 式品牌色光晕）：

- **地址栏式筛选框**：打开即可打字筛选，方向键选择，回车打开，`1–9` 直达；`Esc` 先清空筛选。
- **自适应网格**：1–3 个大方块一行，4 个 2×2，5–9 个 3 列，10 个以上 4 列紧凑排。每个应用标明状态（当前 / 运行中 / 播放中 / 已休眠 / 加载中 / 未打开），当前应用带取自网站图标的品牌色光晕和指示条。
- **详情条**：悬停或键盘选中哪个应用，下方就显示它的名称、状态和当前网址，并提供休眠、关闭和更多操作。
- **当前页面卡片**：底部随当前标签变化——新网站直接“添加”；已是 Favorite 时提供“编辑”；离开初始页面时提供“回到初始页 / 设为初始页”；同站的另一个标签可“切换过去”；浏览器页面说明不能加入。
- **站内链接也开新标签**（App 主页模式）：YouTube 默认开启——在 YouTube Favorite 里点视频会进入新的普通标签，Favorite 停在首页；其他网站可在编辑面板里打开。
- **编辑面板**从图标处展开：名称、Emoji、初始网址（可一键用当前页）、外链分流开关；移除需要再点一次确认。
- **名称自动取自网站**（页面声明的应用名，或清洗后的标题），“首页-个性推荐-哔哩哔哩”显示为“哔哩哔哩”。添加后可在提示里一键改名。
- **拖动排序**改为指针拖拽，其他图标弹簧让位；`⌥⇧ + 方向键` 也能排序。所有动效遵循系统“减少动态效果”。

**重启后多出 about:blank 的修复**：

- 新建的固定标签只在页面提交后才休眠，并在后台完成，不再因过早休眠停在空白页。
- 启动匹配不再休眠 Chrome 正在恢复的占位标签。
- 补建缺失入口前，先复用上次遗留的空白固定标签，而不是再开一个。
- 弹窗发现无人认领的空白固定标签时会提示，可一键关闭（右上角计数按钮里也有）。
- 计数按钮菜单可“复制诊断信息”：本机记录的恢复、修复、休眠决策，便于排查。

## 日常使用

- 在 Chrome 标签上右键“固定标签页”，即加入 Favorites；“取消固定”会移除其持久定义。
- 在网页内右键“加入 Favorites（固定标签页）”，也可以添加。如果失败，工具栏图标临时显示 `!`，悬停可查看原因。
- 点击工具栏图标：底部卡片添加当前页；点图标打开应用；悬停后的 `⋮`、右键或详情条管理。
- 每个主机名只保留一个 Favorite，`www.` 前缀视为相同；不同子域名可以分开添加。已有实例时，额外同站固定标签保持普通固定标签；没有实例时可以收编。
- 最多保存 12 个 Favorite；名称、Emoji 和初始网址都可编辑。初始网址保留 `#` 路由，不接受包含用户名或密码的网址。

| 操作 | 页面和入口行为 |
| --- | --- |
| 点击 Favorite | 切到已有实例；已休眠则恢复当前网址；未打开则从初始网址新建 |
| 休眠，保留固定标签 | 使用 Chrome discard 释放内存，保留当前网址和固定入口；唤醒会重新加载网页 |
| 关闭页面，保留 Favorite | 移除当前标签，保留弹窗中的定义；下次打开从初始网址开始 |
| 原生 Cmd/Ctrl+W | 从初始网址后台补回固定入口，尝试立即休眠，不抢焦点 |
| 关闭整个窗口 | 保留定义，不重开窗口；之后可从弹窗打开 |
| 回到初始页面 | 当前实例导航到保存的初始网址 |
| 将当前页面设为初始页面 | 修改下一次从头打开时使用的网址 |
| 取消固定并移除 | 删除定义，当前页面保留为普通标签 |

Chrome 重启会先匹配浏览器恢复的固定标签，再补建缺失入口。匹配使用会话 tab ID、上次网址、初始网址和站点身份，并识别 `pendingUrl`。补建时尽量休眠，Chrome 拒绝休眠时保留正常加载的标签。已知归属的空白入口可在启动匹配或点击时导回保存的网址。

跨窗口切换会给一个短暂的工具栏角标和页面提示。Chrome 标签 ID 只在一次浏览器会话内有效，工作线程日常唤醒不会重复清掉 ID。

## 键盘操作

- `Cmd/Ctrl+Shift+Y`：打开管理弹窗，可在 `chrome://extensions/shortcuts` 修改。
- 直接打字筛选；`1–9` 打开对应位置（筛选为空时）；方向键选择，`Enter` 打开，`Esc` 清空筛选。
- `F2` 编辑选中项；`Shift+F10` 或菜单键打开管理菜单；`Alt+Shift+方向键` 移动排序。
- 菜单内方向键、`Home` / `End` 选择，`Enter` 执行，`Escape` 关闭；编辑面板 `Enter` 保存、`Esc` 取消。

## 外部链接

仅在运行中的 Favorite 页面安装小型链接守卫：

- 当前注册域名内的普通链接继续在 Favorite 中浏览。
- 指向另一个 Favorite：运行中则切过去并保留其页面状态；休眠或未打开则使用点击的网址唤醒。当前 Favorite 保持原样。
- 其他站点的普通链接在普通标签中打开。
- 同站 `_blank` 普通左键链接留在当前 Favorite；跨站 `_blank` 保持 Chrome 默认的新标签行为。
- Cmd/Ctrl、Shift、Alt 修饰点击、下载链接、表单、脚本导航保持默认行为。守卫跟随实际页面所在站点，支持 OAuth 重定向后的后续浏览。
- 取消固定或移除后停用守卫；后台不可达时回退到原始网址导航。

## 权限与数据

使用 `tabs`、`storage`、`contextMenus`、`scripting`、`favicon`，以及 HTTP/HTTPS 网站访问权限。用途分别为标签管理、本机存储、网页右键菜单、链接守卫及 Chrome favicon 缓存。Chrome 会显示标准的网站数据访问提示；本扩展不读取网页正文，不包含远程服务、账号、分析或遥测。

如果 Chrome 收回了某个 Favorite 网站的访问权限（例如扩展详情里“网站访问权限”改成“点击时”，或重新安装 CRX 后），链接分流不会生效，弹窗会显示黄色提示条，点“允许”即可恢复，无需刷新网页。添加或编辑 Favorite 时也会顺带请求该网站的权限。自定义视图保存在弹窗本地，Favorite 定义在 `chrome.storage.local`，实例映射在 `chrome.storage.session`。启动时校验并修复损坏或重复记录。

## 开发与验证

```bash
npm install
npm run dev
npm run check
npm run package
```

- `npm run dev` 后打开 `http://127.0.0.1:5173/popup.html`，使用示例数据验证交互，不连接真实 Chrome 标签。参数：`?n=0–12` 应用数量，`?ctx=addable|favorite|deep|unsupported` 当前页面情形，`?blanks=2` 空白标签提示。
- 弹窗源码在 `src/popup/`（Preact），后台与领域逻辑在 `src/core/`；设计稿在 `design/`。
- `npm run check`：TypeScript + Vitest；覆盖领域规则、存储迁移、标签生命周期、Chrome API 适配、后台启动与事件、键盘和显示状态。
- `npm run build`：生成可加载的 `dist`，不包含 source map。
- `npm run package`：构建并生成 `arc-favorites-chrome.zip`。
- 验证结果和仍需在真实 Chrome 中验证的项目见 [QA.md](QA.md)。

项目已使用 git 管理；`.pem` 私钥、CRX 和 ZIP 不进入仓库。私钥用于保持扩展 ID，请勿泄露或删除。

## Chrome 平台边界

- 图标网格出现在管理弹窗中。扩展无法在 Chrome 原生标签栏添加 Arc 的专属 Favorites 区域，也无法改变原生标签的形状、加载动画或右键菜单。
- 原生标签的标题和 favicon 由网站与 Chrome 决定；自定义名称和 Emoji 仅在弹窗显示。
- Chrome 扩展无法拦截原生 Cmd/Ctrl+W，只能在关闭后恢复入口。关闭前的未保存表单和内存状态无法保证恢复；discard 唤醒也会重载页面。
- 跨窗口使用全局单实例，Chrome 每个窗口不会像 Arc Spaces 一样显示同一组虚拟入口；可用工具栏弹窗切换。
- Arc Peek 无法对任意网站可靠复刻，外站链接使用普通标签。
- Chrome 控制 popup 宿主窗口和阴影；扩展只能设计内部内容。
